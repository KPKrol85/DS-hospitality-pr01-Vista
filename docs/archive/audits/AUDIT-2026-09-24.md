**Audit date:** 2026-09-23

**Closure evidence:** Dated 2026-09-24; no separate closure date was recorded.

**Project type:** Demonstrational static multi-page hospitality site (HTML, CSS, Vanilla JavaScript)

**Audit mode:** Final repository and implementation review

**Readiness at original audit:** Needs important fixes

**Original rating:** 7/10

**Archive status:** CLOSED — all four findings resolved with recorded verification.

## 1. Scope and assessment

The audit covered all 11 root HTML routes, shared CSS and JavaScript modules, links, metadata, JSON-LD, images and fonts, build and validation scripts, package metadata, Netlify configuration, manifest, service worker, image pipeline, license, README and settings. It compared canonical sources with a newly generated, ignored `dist/` package. Archived review and plan findings were treated as historical context.

**Original assessment (2026-09-23):** The source-to-distribution pipeline was coherent, the 11-page package built successfully, and sampled packaged routes showed no script errors or missing local assets. Recorded strengths included bundle regeneration from `css/style.css` and `js/script.js`, a worker version derived from packaged bytes, visible no-JavaScript reveal content, working room filtering and lightbox dismissal, Vista-scoped worker caches with an offline fallback, and native contact-form constraints without JavaScript (excluding date-range validation). Three P1 issues required correction before final public presentation. No P0 risks or extra quality improvements were detected.

## 2. Closed findings

### P0 — Critical risks

None detected.

### P1 — Important issues

#### [P1-01] Closed mobile navigation leaves invisible links in keyboard order

- **Status:** COMPLETED — verified.
- **Resolution:** The closed JavaScript-controlled navigation (`.js .site-nav[hidden]`) is no longer rendered, while opening, focus return, breakpoint, desktop and no-JavaScript behavior are preserved.
- **Verification:** Local Chromium on source and a fresh `build:dist` package (11 pages) passed closed-menu Tab/Shift+Tab exclusion at 390 px, open-menu focus, toggle/Escape/link closing with focus return, desktop navigation at 1280 px and no-JavaScript navigation.

#### [P1-02] Inquiry form accepts arrival dates in the past

- **Status:** COMPLETED — verified.
- **Resolution:** Enhanced submit validation rejects past arrivals against the refreshed browser-local date, and a Netlify Edge Function rejects past arrivals by the Europe/Warsaw date, including no-JavaScript requests.
- **Verification:** Local Chromium on source and a fresh package blocked past arrivals and passed valid inquiries to a local POST interceptor, and the Edge handler's local request checks passed. The project owner confirmed HTTP 422 for a deployed POST with arrival `2025-01-01` and Netlify's success response for a valid inquiry.

#### [P1-03] Indexable structured data presents the fictional brand as a real hotel

- **Status:** COMPLETED — verified.
- **Resolution:** JSON-LD on the six indexable pages no longer contains `Hotel`, `#hotel`, location or customer-service claims, and visible contact details are attributed to KP_Code Digital Studio while Vista remains a fictional brand.
- **Verification:** All six embedded/fetched JSON-LD pairs matched in source and a fresh package; local Chrome 153 passed fetched, fallback and no-JavaScript presentation, and all 11 footers passed 390/1280 px light/dark checks.

### P2 — Minor refinements

#### [P2-01] README accessibility description contradicts the current no-JavaScript baseline

- **Status:** COMPLETED — verified.
- **Resolution:** Both README languages now describe the visible reveal fallback, native constraints before enhanced initialization, browser-local and Europe/Warsaw arrival-date rules, and retain the WCAG disclaimer without a form-collection claim.
- **Verification:** Focused source inspection and comparison with the recorded P1-02 checks confirmed Polish/English factual parity; no tests, build or deployment were run for this documentation correction.

## 3. Final verification

### Original audit verification (2026-09-23)

- `npm run check:links` passed for 11 HTML files and `sitemap.xml`; `node --check` passed for 23 JavaScript files; all 11 `assets/seo/*.json` files parsed.
- `npm run build` passed and generated an 11-page ignored `dist/` package without changing tracked source files.
- Local Headless Chromium confirmed one `h1`, a `main`, no page script errors and no failed local asset responses on all 11 source and packaged routes; five packaged routes at 390 px showed no horizontal overflow. Mobile-menu keyboard traversal, room filtering, lightbox dismissal, no-JavaScript visibility and form constraints were tested; enhanced submission was intercepted and no inquiry was sent.
- With a test server supplying `Service-Worker-Allowed: /`, the production worker controlled the page, created Vista caches and served a cached rooms page offline.

### Closure verification (2026-09-24)

Recorded in [the completed 2026-09-24 plan](../plans/PLAN-2026-09-24.md): focused local Chromium checks on source and fresh `build:dist` packages for P1-01 to P1-03, structured-data pair comparison, owner-confirmed production checks for P1-02, and source comparison for P2-01. `git diff --check` passed for the P1-03 change.

## 4. Limitations

- **Original audit:** No live URL was supplied; public deployment, Netlify Forms processing, actual headers and redirects, third-party map rendering and search-engine treatment were not tested. The worker scope header was simulated locally. `npm run test:a11y` was not run because it could install the absent `axe-core`. Other browsers, assistive technologies, production performance and WCAG conformance were not assessed.
- **Closure:** Inspection of the valid inquiry in the Netlify Forms dashboard was not documented. Static HTML has no moving arrival minimum, so no-JavaScript rejection relies on the Edge Function; its Europe/Warsaw date can differ from the visitor's local date. P1-03 checks establish source consistency, not search-engine treatment or live Google Maps rendering. The P1-03 build reported an outdated Browserslist dataset; no dependencies were updated.

The assessment did not certify live deployment, inquiry delivery, accessibility compliance or search-engine outcomes.
