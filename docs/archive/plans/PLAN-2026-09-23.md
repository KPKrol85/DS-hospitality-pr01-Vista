# Vista — Development Plan

**Last reviewed:** 2026-09-20

**Project type:** Demonstrational static multi-page hospitality site (HTML, CSS, Vanilla JavaScript)

**Source:** Focused front-end review dated 2026-09-20 ([archived review](../audits/REVIEW-2026-09-23.md))

**Completion date:** Not recorded; archived as `PLAN-2026-09-23.md`.

**Status:** COMPLETED — all five required objectives and both optional improvements verified; this plan is archived.

## Scope

The plan resolved the seven review findings covering progressive enhancement, contact-form validation, dialog focus, stale production bundles, license metadata, image-cache freshness and contact-map recovery. Root HTML, `css/` and `js/` were the canonical sources; production bundles and `dist/` were generated output.

By owner decision, the clean production-build workflow (`PH2-01`) was established before the visitor-facing corrections. This changed the work order only: final packaged verification of `PH1-01`–`PH1-03` remained part of `PH2-01`.

## Phase 1 — Visitor-facing behavior

- [x] **PH1-01 — Make reveal content visible by default** — `[data-reveal]` content is visible before JavaScript activation and after failed initialization, while the enhanced reveal transition is retained; verified on representative homepage and subpage content with JavaScript disabled and enabled (review `P1-01`).
- [x] **PH1-02 — Preserve native contact-form validation** — Native constraints for required fields, email, phone pattern, guest bounds and consent remain active without JavaScript, while the enhanced handler keeps its messages and the Netlify Forms route; invalid no-JavaScript submissions were blocked by the browser and enhanced valid/invalid handling passed locally (review `P1-05`).
- [x] **PH1-03 — Contain focus in open dialogs** — The project notice and gallery lightbox keep Tab and Shift+Tab inside the dialog from the initially focused container, block background focus and restore the previous focus target on close; forward and reverse traversal was verified for both dialogs (review `P1-03`).

## Phase 2 — Distribution and project declarations

- [x] **PH2-01 — Keep production bundles aligned with source** — CSS and JavaScript bundles are generated directly in `dist/` from canonical sources, `build` and `build:dist` both rebuild a clean package, and Service Worker registration remains production-only; fresh builds packaged 11 HTML pages with bundle and link checks passing, and local Headless Chromium 147 matched source and production behavior (review `P1-02`).
- [x] **PH2-02 — Align project license declarations** — `package.json` and the root `package-lock.json` entry were aligned with `LICENSE`, the Polish and English README statements were confirmed and third-party dependency licenses were preserved; consistency across `LICENSE` and project metadata was recorded without further method detail (review `P1-04`).

## Optional improvements

Originally listed as non-blocking optional future improvements; both were completed in this cycle.

- [x] **O-01 — Refresh cached images after same-URL updates** — A replaced image published at an existing URL reaches returning visitors after an updated distribution is installed; verified with a same-URL A → B production-package update in persistent Chromium (review `P2-01`).
- [x] **O-02 — Reveal the map after a late successful load** — A late successful iframe load reveals the interactive map, while failed or slow loads retain the fallback and external map link; local Chromium with mocked iframe responses passed early and post-timeout loads, a synthetic error, a never-completing request and the no-JavaScript fallback, including link and iframe visibility/accessibility attributes (review `P2-02`).

## Completion

- **Verified tasks:** 7/7 — five required objectives (`PH1-01`–`PH1-03`, `PH2-01`–`PH2-02`) and two optional improvements (`O-01`–`O-02`).
- **Outcome:** All seven review findings were resolved, and the final packaged site was verified against current source behavior in `PH2-01`.
- **Limitations:** Verification was local. The valid Netlify Forms POST was intercepted; no live Netlify deployment, inquiry delivery or third-party map rendering was tested.
